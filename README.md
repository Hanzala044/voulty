## ✨ Features

- 🏦 **Private Vaults:** Create secure groups with shared access codes and optional PIN protection.
- 🧾 **AI Receipt Intelligence:** (Upcoming) Intelligent receipt scanning and automated categorical split.
- 📄 **Digital Receipts:** Generate and download professional PDF receipts for any transaction.
- 🗺️ **Full Map Insights:** Visualize your spending geographically with interactive heatmaps.
- 🤖 **Gemini AI ChatBot:** Get instant, context-aware financial advice and budget analysis.
- 📊 **Dynamic Analytics:** Real-time visibility into your contributions, balances, and history.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Hanzala044/voulty.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env.local` file and add your Google Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
4. Launch the development server:
   ```bash
   npm run dev
   ```
